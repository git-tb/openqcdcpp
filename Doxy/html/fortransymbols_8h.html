◆ NXPLIM

#define NXPLIM   201

Here we import some symbols from the old fortran code in order to use and modify them in our code. COMMON blocks from Fortran can be imported by mapping them to structs with the same order of member variables as defined in the Fortran code.

Depending on the compiler the symbol names from the Fortran source code are changed slightly in the corresponding object files that we link to the C++ program, hence the trailing underscore "name_" at the end of each variable name.

Check for the precise symbols names with

‍ nm libMyLib.so | grep symbolname
