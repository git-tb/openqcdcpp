Here's how I understand it so far, based on (Schwartz QFT, eq. 26.102) Let a = \alphas_s/4Pi and aR = \alpha_s^R(\mu)/4Pi ...the renormalized coupling

F = F(0) + a * F(1) + a**2 * F(2) + ...

For renormalization of amplitudes, replace a -> aR (1 - aR * beta0*ln(Q2/muR2) + aR**2 * (-beta1*ln(Q2/muR2 + beta0**2 * ln**2(Q2/muR2))) + ...) Organizing F in order of the renormalized coupling we get

F = F(0) + aR * F(1) + aR**2 ( F(2) - beta0*ln(Q2/muR2) F(1) ) + aR**3 ( F(3) - beta0*ln(Q2/muR2) F(2) + (....) F(1))

We instead organize F in contributions F(i), each of which comes with a different truncation of the factor from the running coupling.
